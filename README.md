# NEWSGRID / भारत

NEWSGRID is a motion-rich India and world news interface with dedicated technology, finance, and climate desks, local weather search, editorial blogs, persistent reactions, and light and dark themes.

## Live site

[Open NEWSGRID](https://premdheeraj.github.io/newsgrid/)

## Highlights

- India, world, technology, finance, and climate news feeds
- Exact-location weather powered by Open-Meteo
- Animated editorial cards and responsive layouts
- Like and dislike reactions saved on the visitor's device
- Accessible light and dark modes

## Local development

```bash
npm install
npm run dev
```

The site is built with React, TypeScript, Vinext, Framer Motion, and Tailwind CSS.
